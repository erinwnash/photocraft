# Roto Mask Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Nuke-Roto-style bezier spline editor that produces a layer's alpha mask, with feather, grouping, per-shape opacity and blend ops, and Nuke `.nk` import/export.

**Architecture:** Pure data `RotoMask` in `photocraft-doc` (L1), a new L2 crate `photocraft-roto` that evaluates it to an `f32` coverage array (same shape as `vector_mask_values`), hooked into `compose::masks::combined_mask`. All edits are engine commands. The CPU evaluator is the oracle; a GPU backend is added last and parity-tested.

**Tech Stack:** Rust 2024 (rust-version 1.90), serde, existing `photocraft-vector` rasterizer, wgpu (phase 8), egui (phase 4).

**Spec:** `docs/superpowers/specs/2026-10-06-roto-mask-design.md`

## Global Constraints

- Rust only; no JS/TS, Tauri, Electron or webview.
- Non-test code never panics: no `unwrap()`, `expect()`, `panic!`, `unreachable!`, `todo!`, `unimplemented!`. Return errors, use `get()`, `checked_*`/`saturating_*`.
- `unsafe_code = "forbid"` (workspace lint).
- Layering enforced by `cargo xtask layers`: a crate may depend only on lower layers. New crate `roto` is registered at `Class::Layer(2)` in `xtask/src/layers.rs`. Nothing below `ui-egui` uses egui.
- Every action is an engine command (undoable, journalled, available to the control channel and MCP).
- Document coordinates are pixels, `f64`, **y down**. Nuke coordinates are y up; convert at the Nuke boundary only.
- Clean-room: no Foundry code or assets. FOSS-first for the Nuke parser (search before writing; record provenance in `THIRD_PARTY_NOTICES.md`).
- Product name is **PhotoCraft** in user-facing text; crate names `photocraft-*`.
- v1 is stills only, bezier only, preset falloffs only.
- Deviation from the spec's `BlendOp` list: `Screen` is dropped because for scalar alpha it equals `Union` (`a + b - ab`). `Intersect` is `min(a, b)`; `Multiply` is `a * b`.

## Review Focus

1. A shape with fewer than 2 points (or all points coincident): renders empty, no panic, no NaN.
2. NaN/inf in any point, handle or feather value: rejected by `RotoMask::validate` and ignored by the evaluator rather than propagating NaN into the mask.
3. Feather handle on a single point only: the soft edge fades smoothly to hard on neighbouring segments, with no seam.
4. Opacity 0 shape, empty group, group with all children hidden: contributes nothing; the mask is exactly the accumulator beneath.
5. Huge blur radius or feather offset (1e9): clamped to the documented cap, bounded allocation, finishes quickly.

```rust
//! Roto mask data: a tree of bezier shapes and groups that evaluates to an alpha mask.
//! Pure data; evaluation lives in `photocraft-roto`. Coordinates are document pixels (f64, y down).

use serde::{Deserialize, Serialize};

pub const MAX_POINTS_PER_SHAPE: usize = 10_000;
pub const MAX_DEPTH: usize = 32;
pub const MAX_NODES: usize = 10_000;
pub const MAX_BLUR: f32 = 1000.0;
pub const MAX_FEATHER: f64 = 10_000.0;

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct NodeId(pub u64);
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct PointId(pub u64);

#[derive(Clone, Copy, Debug, Default, PartialEq, Serialize, Deserialize)]
pub struct V2 {
    pub x: f64,
    pub y: f64,
}
impl V2 {
    pub const ZERO: V2 = V2 { x: 0.0, y: 0.0 };
    pub fn new(x: f64, y: f64) -> Self {
        V2 { x, y }
    }
    pub fn is_finite(&self) -> bool {
        self.x.is_finite() && self.y.is_finite()
    }
}

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Serialize, Deserialize)]
pub enum BlendOp {
    /// `a + b - ab` (alpha over).
    #[default]
    Union,
    /// `a * (1 - b)`.
    Subtract,
    /// `min(a, b)`.
    Intersect,
    Max,
    Min,
    /// `a * b`.
    Multiply,
    /// `|a - b|`.
    Difference,
}

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Serialize, Deserialize)]
pub enum Falloff {
    #[default]
    Linear,
    Smooth,
    EaseIn,
    EaseOut,
}

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Serialize, Deserialize)]
pub enum OverlapMode {
    #[default]
    Max,
    Sum,
    Over,
}

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Serialize, Deserialize)]
pub enum Backend {
    #[default]
    Auto,
    Cpu,
    Gpu,
}

/// Translate, rotate (degrees), scale and skew (degrees) about `pivot`.
#[derive(Clone, Copy, Debug, PartialEq, Serialize, Deserialize)]
pub struct Transform2D {
    pub translate: V2,
    pub rotate: f64,
    pub scale: V2,
    pub skew: f64,
    pub pivot: V2,
}
impl Default for Transform2D {
    fn default() -> Self {
        Transform2D { translate: V2::ZERO, rotate: 0.0, scale: V2::new(1.0, 1.0), skew: 0.0, pivot: V2::ZERO }
    }
}
impl Transform2D {
    pub fn is_finite(&self) -> bool {
        self.translate.is_finite() && self.scale.is_finite() && self.pivot.is_finite() && self.rotate.is_finite() && self.skew.is_finite()
    }
}

/// A bezier point. Handles and the feather offset are relative to `pos`.
#[derive(Clone, Copy, Debug, PartialEq, Serialize, Deserialize)]
pub struct Point {
    pub id: PointId,
    pub pos: V2,
    pub tangent_in: V2,
    pub tangent_out: V2,
    /// Offset of the feather outline from `pos` (zero = no feather at this point).
    pub feather_pos: V2,
    pub feather_in: V2,
    pub feather_out: V2,
    pub smooth: bool,
}
impl Point {
    pub fn corner(id: PointId, x: f64, y: f64) -> Self {
        Point {
            id,
            pos: V2::new(x, y),
            tangent_in: V2::ZERO,
            tangent_out: V2::ZERO,
            feather_pos: V2::ZERO,
            feather_in: V2::ZERO,
            feather_out: V2::ZERO,
            smooth: false,
        }
    }
    fn is_finite(&self) -> bool {
        [self.pos, self.tangent_in, self.tangent_out, self.feather_pos, self.feather_in, self.feather_out].iter().all(V2::is_finite)
    }
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct Shape {
    pub id: NodeId,
    pub name: String,
    pub visible: bool,
    pub locked: bool,
    /// `0..=1`.
    pub opacity: f32,
    pub blend_op: BlendOp,
    pub invert: bool,
    pub closed: bool,
    pub points: Vec<Point>,
    /// Blur radius in px (`0..=MAX_BLUR`).
    pub blur: f32,
    pub falloff: Falloff,
    pub transform: Transform2D,
}
impl Shape {
    pub fn new(id: NodeId, name: &str) -> Self {
        Shape {
            id,
            name: name.into(),
            visible: true,
            locked: false,
            opacity: 1.0,
            blend_op: BlendOp::Union,
            invert: false,
            closed: true,
            points: Vec::new(),
            blur: 0.0,
            falloff: Falloff::Linear,
            transform: Transform2D::default(),
        }
    }
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct Group {
    pub id: NodeId,
    pub name: String,
    pub visible: bool,
    pub locked: bool,
    pub opacity: f32,
    pub blend_op: BlendOp,
    pub transform: Transform2D,
    pub children: Vec<Node>,
}
impl Group {
    pub fn new(id: NodeId, name: &str) -> Self {
        Group { id, name: name.into(), visible: true, locked: false, opacity: 1.0, blend_op: BlendOp::Union, transform: Transform2D::default(), children: Vec::new() }
    }
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub enum Node {
    Group(Group),
    Shape(Shape),
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct RotoMask {
    pub enabled: bool,
    pub linked: bool,
    /// Final multiplier `0..=1`.
    pub density: f32,
    pub invert: bool,
    pub overlap: OverlapMode,
    pub backend: Backend,
    pub root: Group,
}
impl Default for RotoMask {
    fn default() -> Self {
        RotoMask { enabled: true, linked: true, density: 1.0, invert: false, overlap: OverlapMode::Max, backend: Backend::Auto, root: Group::new(NodeId(0), "Root") }
    }
}

#[derive(Clone, Debug, PartialEq, Eq, thiserror::Error)]
pub enum RotoError {
    #[error("non-finite value in {0}")]
    NonFinite(String),
    #[error("tree deeper than {MAX_DEPTH}")]
    TooDeep,
    #[error("too many nodes (max {MAX_NODES})")]
    TooManyNodes,
    #[error("too many points in shape {0} (max {MAX_POINTS_PER_SHAPE})")]
    TooManyPoints(String),
    #[error("value out of range: {0}")]
    OutOfRange(String),
}

impl RotoMask {
    /// Checks caps and finiteness. Evaluators call this and treat an `Err` as an empty mask.
    pub fn validate(&self) -> Result<(), RotoError> {
        if !self.density.is_finite() || !(0.0..=1.0).contains(&self.density) {
            return Err(RotoError::OutOfRange("density".into()));
        }
        let mut count = 0usize;
        validate_group(&self.root, 0, &mut count)
    }
}

fn unit(v: f32, what: &str) -> Result<(), RotoError> {
    if v.is_finite() && (0.0..=1.0).contains(&v) { Ok(()) } else { Err(RotoError::OutOfRange(format!("{what} opacity"))) }
}

fn validate_group(g: &Group, depth: usize, count: &mut usize) -> Result<(), RotoError> {
    if depth > MAX_DEPTH {
        return Err(RotoError::TooDeep);
    }
    unit(g.opacity, &g.name)?;
    if !g.transform.is_finite() {
        return Err(RotoError::NonFinite(g.name.clone()));
    }
    for n in &g.children {
        *count += 1;
        if *count > MAX_NODES {
            return Err(RotoError::TooManyNodes);
        }
        match n {
            Node::Group(c) => validate_group(c, depth + 1, count)?,
            Node::Shape(s) => {
                unit(s.opacity, &s.name)?;
                if s.points.len() > MAX_POINTS_PER_SHAPE {
                    return Err(RotoError::TooManyPoints(s.name.clone()));
                }
                if !s.blur.is_finite() || !(0.0..=MAX_BLUR).contains(&s.blur) {
                    return Err(RotoError::OutOfRange(format!("{} blur", s.name)));
                }
                if !s.transform.is_finite() || !s.points.iter().all(Point::is_finite) {
                    return Err(RotoError::NonFinite(s.name.clone()));
                }
            }
        }
    }
    Ok(())
}
```

```rust
use photocraft_doc::BlendOp;

/// Combines `b` (the new contribution) into `a` (the accumulator beneath), both `0..=1`.
pub fn blend(op: BlendOp, a: f32, b: f32) -> f32 {
    match op {
        BlendOp::Union => a + b - a * b,
        BlendOp::Subtract => a * (1.0 - b),
        BlendOp::Intersect | BlendOp::Min => a.min(b),
        BlendOp::Max => a.max(b),
        BlendOp::Multiply => a * b,
        BlendOp::Difference => (a - b).abs(),
    }
}
```

```rust
use photocraft_doc::{Knot, Path, Point as RPoint, Shape, Subpath, Transform2D, V2};
use photocraft_geom::Point;

/// Applies translate/rotate/scale/skew about the pivot.
pub fn transform_point(t: &Transform2D, p: V2) -> V2 {
    let (dx, dy) = (p.x - t.pivot.x, p.y - t.pivot.y);
    let (sx, sy) = (dx * t.scale.x, dy * t.scale.y);
    let sk = t.skew.to_radians().tan();
    let (kx, ky) = (sx + sy * sk, sy);
    let (s, c) = t.rotate.to_radians().sin_cos();
    V2::new(t.pivot.x + t.translate.x + kx * c - ky * s, t.pivot.y + t.translate.y + kx * s + ky * c)
}

/// Vectors (handles/offsets) transform without the translate and pivot.
pub fn transform_vec(t: &Transform2D, v: V2) -> V2 {
    let z = Transform2D { translate: V2::ZERO, pivot: V2::ZERO, ..*t };
    transform_point(&z, v)
}

fn gp(v: V2) -> Point {
    Point::new(v.x, v.y)
}

fn knot(p: &RPoint, xf: &[Transform2D], feather: bool) -> Knot {
    let apply_p = |v: V2| xf.iter().fold(v, |acc, t| transform_point(t, acc));
    let apply_v = |v: V2| xf.iter().fold(v, |acc, t| transform_vec(t, acc));
    let anchor_local = if feather { V2::new(p.pos.x + p.feather_pos.x, p.pos.y + p.feather_pos.y) } else { p.pos };
    let (tin, tout) = if feather { (p.feather_in, p.feather_out) } else { (p.tangent_in, p.tangent_out) };
    let anchor = apply_p(anchor_local);
    let in_c = apply_p(V2::new(anchor_local.x + tin.x, anchor_local.y + tin.y));
    let out_c = apply_p(V2::new(anchor_local.x + tout.x, anchor_local.y + tout.y));
    let _ = apply_v;
    Knot { anchor: gp(anchor), in_ctrl: gp(in_c), out_ctrl: gp(out_c), smooth: p.smooth }
}

/// The shape outline (`feather == false`) or feather outline as a path. `xf` is the transform
/// chain, innermost (the shape's own) first.
pub fn outline_path(s: &Shape, xf: &[Transform2D], feather: bool) -> Path {
    let mut p = Path::default();
    if s.points.len() < 2 {
        return p;
    }
    let knots = s.points.iter().map(|pt| knot(pt, xf, feather)).collect();
    p.subpaths.push(Subpath { knots, closed: s.closed, ..Default::default() });
    p
}
```

```rust
use photocraft_doc::{Group, Node, RotoMask, Shape, Transform2D};
use photocraft_geom::Rect;

use crate::blend::blend;
use crate::curve::outline_path;

/// Pixels the evaluator will allocate for one call (guards hostile rects).
const MAX_PIXELS: usize = 1 << 28;

/// Coverage of `m` over `rect` (row-major, `0..=1`). Invalid masks and empty or oversized
/// rects give an empty mask or zeros rather than an error.
pub fn roto_values(m: &RotoMask, rect: Rect) -> Vec<f32> {
    let (w, h) = (rect.width().max(0) as usize, rect.height().max(0) as usize);
    let Some(n) = w.checked_mul(h).filter(|n| *n <= MAX_PIXELS) else { return Vec::new() };
    if n == 0 {
        return Vec::new();
    }
    if m.validate().is_err() {
        return vec![0.0; n];
    }
    let mut acc = vec![0.0f32; n];
    let mut xf: Vec<Transform2D> = Vec::new();
    eval_children(&m.root, rect, &mut xf, &mut acc);
    for v in &mut acc {
        let mut x = v.clamp(0.0, 1.0);
        if m.invert {
            x = 1.0 - x;
        }
        *v = x * m.density;
    }
    acc
}

fn eval_children(g: &Group, rect: Rect, xf: &mut Vec<Transform2D>, acc: &mut [f32]) {
    for node in &g.children {
        match node {
            Node::Shape(s) if s.visible => {
                let cov = shape_coverage(s, rect, xf);
                combine(acc, &cov, s.blend_op, s.opacity);
            }
            Node::Group(c) if c.visible => {
                let mut iso = vec![0.0f32; acc.len()];
                xf.push(c.transform);
                eval_children(c, rect, xf, &mut iso);
                xf.pop();
                combine(acc, &iso, c.blend_op, c.opacity);
            }
            _ => {}
        }
    }
}

fn combine(acc: &mut [f32], src: &[f32], op: photocraft_doc::BlendOp, opacity: f32) {
    for (a, b) in acc.iter_mut().zip(src) {
        let a0 = *a;
        let blended = blend(op, a0, *b);
        // Opacity mixes the blended result with what was beneath.
        *a = a0 + (blended - a0) * opacity;
    }
}

/// One shape's coverage (hard edge in this task; feather, blur and invert land in later tasks).
pub(crate) fn shape_coverage(s: &Shape, rect: Rect, xf: &[Transform2D]) -> Vec<f32> {
    let mut chain = Vec::with_capacity(xf.len() + 1);
    chain.push(s.transform);
    chain.extend(xf.iter().rev().copied());
    let path = outline_path(s, &chain, false);
    if path.subpaths.is_empty() {
        return vec![0.0; (rect.width().max(0) as usize) * (rect.height().max(0) as usize)];
    }
    photocraft_vector::path_coverage(&path, rect)
}
```

Note on transform order: the shape's own transform applies first, then each enclosing group's from innermost to outermost; `xf` is stored outermost-first, hence the `rev()`.

```rust
use photocraft_doc::Falloff;

/// Maps the band parameter `x` (0 at the feather edge, 1 at the shape side) through a preset.
pub(crate) fn falloff(f: Falloff, x: f32) -> f32 {
    let x = x.clamp(0.0, 1.0);
    match f {
        Falloff::Linear => x,
        Falloff::Smooth => x * x * (3.0 - 2.0 * x),
        Falloff::EaseIn => x * x,
        Falloff::EaseOut => 1.0 - (1.0 - x) * (1.0 - x),
    }
}
```

`feather_band` algorithm (implement exactly this):

1. Flatten both outlines with the **same** per-segment sample count. Do not use `vector::flatten` for the feather curve independently; instead write a local `sample_segment(p0, c0, c1, p1, n) -> Vec<(f64, f64)>` using the cubic bezier formula, and choose `n = clamp(ceil(max(len_shape_polyline, len_feather_polyline) / 2.0), 8, 256)` per segment, where each length is the control-polygon length. This keeps sample *i* paired across the two curves.
2. Per point *k*, `outward_k = dot(feather_pos_k, outward_normal_k) >= 0`, where the normal is the perpendicular of the (prev→next) chord, oriented away from the polygon centroid. A zero `feather_pos` point has `outward_k = true` and contributes a zero-width band.
3. The **core polygon** replaces the vertex at a point whose feather is inward by its feather vertex (so the solid fill shrinks to the inward feather outline). Fill it with `photocraft_vector::fill_rasterizer` on a path built from those vertices (`render(rect)` gives the coverage).
4. For each consecutive sample pair `(i, i+1)`, form the quad `(P_i, P_{i+1}, F_{i+1}, F_i)` and rasterize it as two triangles with a per-vertex alpha: `P` vertices get `a_P = if outward {1} else {0}`, `F` vertices `a_F = 1 - a_P`; vertex alpha is interpolated linearly along the segment between its two end points' values, then mapped through `falloff`. Rasterization samples pixel centres with barycentric weights over the triangle's bounding box clipped to `rect`; a pixel's value is `falloff(interpolated)`, written with `combine_overlap(mode, existing, value)`.
5. `combine_overlap`: `Max => a.max(b)`, `Sum => (a + b).min(1.0)`, `Over => a + b - a * b`.
6. Final shape coverage = `combine_overlap(mode, core, band)`; NaN anywhere is replaced by 0.

Cap: clamp each `feather_pos` component to `±MAX_FEATHER` before use. Skip the band entirely if no point has a nonzero feather (so hard shapes cost nothing extra).

Tokenizer and mapping (the decoded format, from the spec's section 6.1):
- Input cap `MAX_NK_BYTES = 32 MiB` (`NukeError::TooLarge`); nesting cap 64 (return `Syntax`, never recurse deeper). Parse braces into a `Brace { tokens, children }` tree iteratively with an explicit stack.
- Floats: token `x[0-9a-fA-F]{1,8}` is `f32::from_bits(u32)`; `0` is `0.0`; otherwise parse as decimal `f32`. A non-finite result is a warning and is replaced by 0.

- A shape holds two `cc` curves; each `{px N ...}` yields point triples `[tangent_in, pos, tangent_out]`. The first `cc` is the outline; the second is the feather: its position slot is `feather_pos` (offset), its tangent slots are `feather_in`/`feather_out`. Convert y-up to y-down with `y_doc = doc_height - y` for positions, and negate y for tangents and offsets.
- Unknown attribute blocks (`a osw ...`, `tx`, `tt`) become a single de-duplicated warning each; `{tx ...}` is not applied until a translated sample confirms its meaning (recorded as a warning: "shape transform ignored").
- Animated values (a `{x...}` followed by key lists) are sampled at `frame` where the format makes that unambiguous; otherwise the first key is used and a warning is added.
